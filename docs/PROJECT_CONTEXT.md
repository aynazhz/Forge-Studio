# زمینه پروژه کارشناسی Forge Studio

عنوان: طراحی و پیاده‌سازی محیط توسعه یکپارچه تحت وب با قابلیت ویرایش بصری و دستیار هوشمند.

## هدف و تصمیم‌ها
محصول سه تجربه را در یک Workspace ترکیب می‌کند: IDE واقعی (مدیریت پروژه و فایل، ویرایش کد، اجرا و مشاهده خروجی)، ویرایش بصری UI با انعکاس تغییرات پشتیبانی‌شده در کد، و تجربه ثبت تسک و بررسی تغییرات شبیه Codex. تمرکز اصلی Frontend است؛ AI کمکی، کوچک و قابل ارزیابی است. هدف ساخت VS Code/Figma/Codex کامل نیست. این پروژه برای کارشناسی و نمونه‌کار فرانت است.
نسخه اولیه desktop-first، React/TypeScript، local-first و محدود به پروژه‌های React است. فایل‌های کد منبع حقیقت‌اند. ویرایش بصری یا دستیار نباید نسخه مستقلی از کد بسازد. AI نباید بدون تأیید کاربر تغییرات را اعمال کند.
فناوری‌های پیشنهادی: React/Vite/TypeScript، Monaco، Zustand در صورت نیاز، IndexedDB، runtime مرورگری (Sandpack برای آزمایش اول؛ WebContainers برای اجرای کامل‌تر و terminal واقعی در مرحله سوم پس از بررسی امکان‌پذیری و مجوز)، Babel/Recast برای تغییر محدود AST، مدل کوچک تشخیص قصد کاربر، Vitest و Playwright. انتخاب نهایی تابع شواهد است، نه الزام به تمام کتابخانه‌ها.

## مراحل
۱. اثبات اجرای واقعی React در مرورگر و اتصال تغییرات Monaco به Preview. نمونه فنی و ثبت شواهد، خطاها و محدودیت‌ها.
۲. طراحی Workspace و مدیریت فایل‌ها، پوشه‌ها، تب‌ها، ویرایشگر و ذخیره محلی. اتصال اثبات مرحله اول به هسته IDE.
۳. Runtime کامل‌تر، Live Preview و Terminal واقعی و نمایش خطاها؛ تصمیم runtime بر اساس نمونه مرحله اول.
۴. Visual Inspector: انتخاب المان و نگاشت قابل اعتماد به کد، تغییر متن و استایل‌های ثابت محدود از طریق AST، رد تغییرات پشتیبانی‌نشده، تست صحت.
۵. Task Assistant: تشخیص دستورهای محدود با مدل کوچک، اعتبارسنجی، ساخت patch قطعی، diff و Accept/Reject. سنجش دقت با داده آزمون مستقل؛ در دستورات نامشخص درخواست توضیح.
۶. تست یکپارچه، export ZIP، بهینه‌سازی، مستندات و دموی کارشناسی.

پس از کارشناسی: GitHub و تاریخچه، LLM قابل تعویض و تغییرات چندفایلی، ویرایشگر بصری پیشرفته و سپس cloud/collaboration با اجرای ایزوله. هیچ‌یک جزو دو مرحله نخست نیست.

## دموی نهایی و ارزیابی
ایجاد پروژه، ویرایش App.tsx، مشاهده خروجی واقعی، تغییر ظاهر با Inspector و مشاهده تغییر در فایل، درخواست ساده دستیار و تأیید diff، ذخیره و export. ارزیابی با زمان به‌روزرسانی Preview، صحت تبدیل AST، دقت تشخیص دستور و سناریوهای قابل تکرار.
